# Phase 6A — games, concessions and specialty core

Baseline: de7fde908d5aa70b90b268aa0145b08c8f7cb3d4 (the deployed seating correction).

This batch covers 28 source-identified rental variants using 22 appearance profiles, plus two explicit reference conflicts. It is not completion of every remaining Phase 6 catalog entry. Core photos were captured from the Friendly website's canonical `/api/item-image/:slug` route. Identity comes from exact `fpr:` slugs, not a similar product name. The customer scene, legacy accessories and side-by-side catalog audit share the same new geometry.

## Model changes

Games: wood Connect Four frame with real 7-by-6 through holes and red/blue counters; two wood cornhole boards with actual holes as one rental set; alternating wood-block stack; green/ivory chess board with 32 differentiated pieces; two ladderball frames; oversized red/blue bucket pong rather than a generic rectangular game/table. Compact game arrangements are product previews, not regulation play-space plans. The 5ft Timbers title and bucket-pong photo do not establish a measured starting height or all included quantities.

Concessions: pink tabletop cotton-candy base with a near-cylindrical open metal bowl and rolled rim; red-top popcorn cabinet with hanging kettle; blue snow-cone drive and metal hopper over a clear bin; vented steel fountain; roller grill with curved clear guard; separate bun-warmer cabinet, pump cheese warmer and hanging-rack pretzel display. No invented carts, food or supplies are added. Fine printed artwork is not reproduced. Surface finish and unnamed dimensions remain approximations.

Specialty: yellow foam cannon/tripod, black lectern and gooseneck microphone, portable speaker with handle and woofer light ring, blue cooler/light lid, open dark trash can, one black retractable-belt stanchion and red runner without added posts. Seven booth duration/attendant SKUs share the photographed upright tablet/ring-light shape while retaining separate product IDs and rental terms. No extra attendant, printing, backdrop, travel or supply charges are generated by drawing a model.

The earlier Phase 6 draft's cotton-candy bowl was too conical; it now follows the near-vertical reference. The bun-warmer no longer receives an unpictured oversized black handle. The grill guard is curved instead of a sloped slab. Negative quarter-turns are handled without changing saved dimensions.

## Data and booking boundaries

No price, stock, customer order, payment, calendar record or visual-approval status is written by this release. Source dimensions, when supplied, take precedence over approximate planning profiles. Model identity/footprint checks do not certify measured dimensions, required clearances, electrical capacity, food-service suitability or other operating safety. Static game previews are not auto-started motion. Existing operation toggles control supported decorative machine motion.

The deployed seating correction is retained. Book Now still transfers exact source IDs/quantities through the existing Friendly cart and checkout; this release does not introduce a second booking database. Core unit tests use synthetic catalog records so they run in a clean clone. Captured live catalog tests, real mesh/render checks and production cart smoke tests are separate. A successful QA branch is not proof of deployment; live runtime hashes and browser checks must pass before the release is reported live.
