## Identity and checkout

Exact source slugs are required for these photo-specific models. Similar names alone never select a model. Lighting matches the current tent dimensions; duplicate/rotated-size mappings fail closed. Hiding tenant prices does not discard valid product identities. Floor/stage ambiguous mappings do not select the first record. The ordinary Book Now selection-only contract is unchanged: Friendly checkout resolves current prices, availability and fees. This release writes no product prices, stock, approvals, customer orders or payments.

## Verification boundaries

Tests cover each source identity, physical section count, saved geometry preservation, finite animated transforms, bounded draw batches, operation stop behavior, installed lighting and booking identities. Browser QA captures all supported models and desktop/mobile audit pages, including explicit Stage Ramp conflict and unknown-product fallback. Existing furniture/equipment/linen focused regressions are retained.

The broader legacy scene-environment test already fails on the throne-king height assertion at the pre-Phase-5 baseline. That unrelated failure is recorded rather than silently weakening the test or claiming the whole repository suite is green. Fine finishes, material response and unspecified dimensions remain approximations. No product is automatically marked approved.
